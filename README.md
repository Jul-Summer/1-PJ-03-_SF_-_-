# 🧠 Face Recognition Classifier (Transfer Learning)

## 📌 Описание проекта

В этом проекте реализован **многоклассовый классификатор изображений лиц знаменитостей** с использованием методов **переноса обучения (Transfer Learning)**.

Задача выполнена в рамках стажировки в стартапе, который разрабатывает систему распознавания лиц для IT-конференции, где выступают известные спикеры.

Цель — обучить модель, которая способна определять личности людей по изображению с точностью:

> 🎯 **Accuracy > 0.85 на валидационной выборке**

---

## 🧩 Задача

Необходимо построить систему, которая:

- классифицирует изображения на 5 классов (5 знаменитостей)
- использует предобученные модели
- обучается на размеченном датасете
- показывает результаты на валидации
- визуализирует предсказания

## 🧠 Подход к решению

### 1. Загрузка данных

Данные загружаются с использованием `DataLoader`:

- train loader
- validation loader
- batch processing

---

### 2. Визуализация данных

Перед обучением выполняется:

- просмотр одного батча изображений
- проверка разметки
- анализ распределения классов

---

### 3. Transfer Learning

Используется предобученная модель:

- ResNet50 / EfficientNet / MobileNet (на выбор)
- заменён классификационный слой под 5 классов

Пример:


model.fc = nn.Linear(in_features, 5)
